## **BACKEND PROMPT: Confidence Threshold Logic (Issue 2 + 3 Combined)**

### **Context**
- **Problem**: Current logic has overlapping thresholds (`ticket > 0.5`, `escalation < 0.7`) causing duplicate records in 0.5–0.7 range with no defined relationship.
- **Fix (Option B)**: Three clear confidence bands with **all tickets starting `pending_review`** (this also resolves Issue 3 — human-in-loop).

---

### **Current Logic (to REPLACE)**
```python
# In inspection_service.py currently:
# ticket if confidence > 0.5 and finding != normal
# escalation if needs_escalation (confidence < 0.7 or safety_critical)
```

### **New Logic (Three Bands + Always Pending Review)**

| Confidence | Ticket Created? | Ticket Status | Escalation Created? |
|------------|-----------------|---------------|---------------------|
| **> 0.7** | ✅ | `pending_review` | ❌ |
| **0.5 – 0.7** | ✅ | `pending_review` | ❌ |
| **< 0.5** | ❌ | — | ✅ `reason=low_confidence` |

> **Note**: In Issue 3 fix, we decided ALL tickets start as `pending_review` — including high-confidence (`> 0.7`). Reviewer must approve → `open`, or reject → `rejected`.

#### 3. `app/services/inspection_service.py` — Replace `create_inspection()` logic

```python
# ===== OLD LOGIC (REMOVE) =====
# if ollama_result["confidence"] > 0.5 and finding != normal:
#     ticket = Ticket(status=TicketStatus.OPEN, ...)
#     if needs_escalation: create escalation

# ===== NEW LOGIC =====
confidence = ollama_result["confidence"]
finding = ollama_result["finding"]
is_normal = finding.strip().lower() in ("normal", "no issue", "ok")
is_safety = needs_escalation and reason == "safety_critical"

if is_normal:
    # No ticket, no escalation — inspection passes
    pass

elif confidence < 0.5 and not is_safety:
    # LOW CONFIDENCE — no ticket, escalation only
    escalation = Escalation(
        ticket_id=None,           # <-- Escalation without ticket now allowed
        reason="low_confidence",
        status=EscalationStatus.PENDING,
    )
    db.add(escalation)

elif confidence >= 0.5 or is_safety:
    # TICKET CREATED — always pending_review (never auto-open)
    ticket = Ticket(
        inspection_id=inspection.id,
        machine_id=machine.id,
        title=f"Inspection finding: {machine.machine_id}",
        description=ollama_result["finding"],
        status=TicketStatus.PENDING_REVIEW,   # <-- Key change
        priority=1 if is_safety else 2,
    )
    db.add(ticket)
    await db.flush()

    # Escalate only if safety-critical (high-confidence safety issue)
    if is_safety:
        escalation = Escalation(
            ticket_id=ticket.id,
            reason="safety_critical",
            status=EscalationStatus.PENDING,
        )
        db.add(escalation)
```
