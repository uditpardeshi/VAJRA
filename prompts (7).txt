## **BACKEND PROMPT: Fix Silent Fallback Confidence (Issue 1)**

### **Context**
- **Problem**: When vision model (qwen2-vl via ngrok) fails, backend returns default confidence (0.5/0.8) → failed inspection can silently pass as "confident" and skip escalation.
- **Fix**: Model failure → HTTP 503, no ticket, clear error to frontend, audit trail.

---

### **Files to Modify**

#### 1. `app/core/exceptions.py` (NEW FILE)
```python
class ModelUnavailableError(Exception):
    """Raised when vision/text model is unreachable or returns invalid response."""
    def __init__(self, reason: str, original_error: Exception | None = None):
        self.reason = reason
        self.original_error = original_error
        super().__init__(f"Model unavailable: {reason}")
```

#### 2. `app/core/model_router.py` — Update `vision_inspect()` and `text_chat()`
- Catch `httpx.TimeoutException`, `httpx.ConnectError`, `json.JSONDecodeError`
- Raise `ModelUnavailableError` with specific reason (`"timeout"`, `"connection_failed"`, `"parse_failed"`)
- **Do not return default/fallback results**

#### 3. `app/services/inspection_service.py` — Update `create_inspection()`
- Wrap `model_router.vision_inspect()` in try/except
- Catch `ModelUnavailableError` → re-raise (don't create inspection/ticket)
- Catch other exceptions → log, raise `ModelUnavailableError("unexpected_error", e)`

#### 4. `app/api/v1/routes_inspect.py` — Update `inspect_equipment()`
- Catch `ModelUnavailableError` → return **HTTP 503** with:
```json
{
  "detail": "MODEL_UNAVAILABLE",
  "reason": "<reason from exception>",
  "message": "AI model unavailable — inspection not recorded. Please retry."
}
```
- **Do not create inspection/ticket on 503**

#### 5. `app/models/tables.py` — Add `model_status` to `Inspection` table
```python
class ModelStatus(str, PyEnum):
    SUCCESS = "success"
    FAILED = "failed"
    TIMEOUT = "timeout"

class Inspection(Base):
    # ... existing columns ...
    model_status = Column(Enum(ModelStatus), default=ModelStatus.SUCCESS, index=True)
```

#### 6. `app/db/init_db.py` — Ensure migration/creation of new column (SQLite: ALTER TABLE)

#### 7. `app/schemas/inspection.py` — Add `model_status` to `InspectResponse`
