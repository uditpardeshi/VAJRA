## ✅ Issues 2 + 3: Confidence Threshold Overlap + Human-in-Loop

**Problem**: Overlapping thresholds (ticket >0.5, escalation <0.7) → duplicate records in 0.5–0.7. High-confidence (>0.7) auto-created `open` tickets with no approval.

**Fix Applied**:
- [ ] Three confidence bands implemented in `inspection_service.create_inspection()`:

| Confidence | Ticket | Status | Escalation |
|------------|--------|--------|------------|
| > 0.7 | ✅ | `pending_review` | ❌ |
| 0.5–0.7 | ✅ | `pending_review` | ❌ |
| < 0.5 | ❌ | — | ✅ `low_confidence` |

- [ ] All tickets start `pending_review` (never auto-`open`)
- [ ] `TicketStatus` enum: added `PENDING_REVIEW`, `REJECTED`
- [ ] `Escalation.ticket_id` → nullable (escalations can exist without tickets for <0.5)
- [ ] `EscalationReason`: `LOW_CONFIDENCE` (only <0.5), `SAFETY_CRITICAL` (high-confidence safety)
- [ ] Reviewer endpoints in `routes_tickets.py`:
  - `GET /tickets/pending-review`
  - `POST /tickets/{id}/approve` → `status=open`, optional `assigned_to`
  - `POST /tickets/{id}/reject` → `status=rejected`, requires `note`
  - `POST /escalations/{id}/convert-to-ticket` (for <0.5 escalations)

**Verification**:

## ✅ Issue 4: WebSocket Auth + Reliability (Level 2)

**Problem**: Query-param auth (spoofable), fire-and-forget broadcasts (message loss).

**Fix Applied**:
- [ ] Added `pyjwt` + `SECRET_KEY` in config
- [ ] `POST /api/v1/auth/ws-token` → short JWT (5 min) with `{user_id, role, type:"ws"}`
- [ ] WS endpoint: `?token=<jwt>` (validates via `decode_ws_token()`)
- [ ] `WebSocketManager` upgrade:
  - Every outbound message gets `msg_id` (UUID)
  - `send_json()` → awaits ACK (3s timeout), retries max 3x (2s backoff)
  - `_ack_received()` removes from retry queue
  - `broadcast_to_role()` / `broadcast_all()` now `await` (ACK + retry)
- [ ] Client contract documented: must send `{"type":"ack","msg_id":...}` for each message
- [ ] Heartbeat: client sends `{"type":"ping"}` every 30s, server replies `pong`

**Verification**:
```bash
# Get token
curl -X POST http://localhost:8000/api/v1/auth/ws-token -d '{"user_id":2,"role":"reviewer"}'
# Connect with token (Python script)
python -c "
import asyncio, websockets, json
async def main():
    async with websockets.connect('ws://localhost:8000/api/v1/ws/escalations?token=<TOKEN>') as ws:
        msg = await ws.recv()
        data = json.loads(msg)
        print('Received:', data)
        await ws.send(json.dumps({'type':'ack','msg_id':data['msg_id']}))
asyncio.run(main())
"
# Expected: connects, receives message, ACK works, no retry needed
```

## ✅ Issue 5: Calculator `eval()` → `simpleeval`

**Problem**: `eval()` in `agent_tools.calculator()` — injection risk.

**Fix Applied**:
- [ ] Added `simpleeval==0.9.13` to `requirements.txt`
- [ ] Replaced `calculator()` in `agent_tools.py`:
  ```python
  from simpleeval import simple_eval
  async def calculator(expression: str):
      allowed_names = {"pi": 3.14159, "e": 2.71828}
      try:
          result = simple_eval(expression, names=allowed_names)
          return {"expression": expression, "result": float(result)}
      except Exception as e:
          return {"error": f"Calculation failed: {str(e)}"}
  ```

**Verification**:
